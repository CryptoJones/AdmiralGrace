# AdmiralGrace UI planning

This directory contains a product and interaction plan for a future AdmiralGrace desktop UI. It is a design proposal, not an implementation commitment. The current repository is an early Rust workspace with a corpus browser CLI and an incomplete disassembly/decompilation engine, so the plan starts with capabilities that can be delivered incrementally.

## Files

- `UI_PLAN.md` — product goals, reference review, layout, workflows, roadmap, and decisions.
- `wireframe.html` — a self-contained static desktop-screen mockup with sample data.

## Open the mockup

Open `wireframe.html` in a browser. It has no dependencies and does not connect to the repository or load binaries.
